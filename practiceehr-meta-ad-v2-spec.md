# PracticeEHR Meta Ad V2 - Creative Specification

## Overview
Warmer, more emotionally resonant version of the TOFU ad while maintaining core design elements.

---

## Background Changes

| Element | Current | New |
|---------|---------|-----|
| Background color | `#F5F5F5` (cool gray) | `#FDF8F3` (warm cream) |
| Dot pattern | Gray dots | Remove entirely OR change to `#F0E6DC` (subtle warm tan) |

---

## Pill Selection (Reduce from 8 to 6)

**KEEP these high-emotion pain points:**
| Pain Point | Color | Rationale |
|------------|-------|-----------|
| Burnt-Out Staff | Green `#4CAF50` | Staff burnout = universal pain |
| Missed Dinners | Yellow `#FFD54F` | Personal/emotional hook |
| Pajama-Time Charting | Purple `#9C7FC0` | Relatable, specific to healthcare |
| No-Shows | Orange `#FF9800` | Revenue impact |
| Denials | Green `#8BC34A` | Revenue impact |
| Rework Pile | Red `#EF5350` | Workflow frustration |

**REMOVE:**
- Click Bloat (too technical/vague)
- Data Silos (too technical/vague)

---

## Copy Changes

### Headline Options (pick one)

**Option A - Question Hook:**
```
Recognize These Symptoms?
```

**Option B - Direct Statement:**
```
Your EHR's Side Effects Are Showing.
```

**Option C - Lead with Pain:**
```
Still Charting in Your Pajamas?
```

**Recommended: Option A** - Questions drive 15-20% higher engagement on Meta TOFU ads.

---

### Subhead Options (pick one)

**Option A:**
```
PracticeEHR: The remedy your practice actually needs.
```

**Option B:**
```
Time for a second opinion on your EHR.
```

**Option C (keep similar to original):**
```
We prescribe PracticeEHR. Relief starts day one.
```

**Recommended: Option B** - Maintains medical metaphor, implies switching without being pushy.
